Privacy policy

Effective 15 November 2026

drive-sync is a personal tool used only by its author, Xiaofeng Han, with his own Google and Microsoft accounts. This policy explains what the tool does with data from those accounts.

Data the tool accesses

  • File and folder metadata (names, sizes, checksums, modification times, identifiers) and file contents in the owner's Google Drive and OneDrive, accessed through the Google Drive API and Microsoft Graph.
  • The account email address and storage quota, shown in the tool's status display.

How the data is used

  • Only to copy files between the owner's two accounts and to show sync status to the owner.
  • File contents pass through the owner's own computers while being copied. They are not stored beyond temporary buffers and short-lived spool files that are deleted after each copy.
  • No advertising, analytics, profiling or machine-learning training. Google user data is used only to provide the sync feature and complies with the Google API Services User Data Policy, including its Limited Use requirements.

Storage and security

  • Sync metadata (identifiers, names, checksums, sync state) is stored on the owner's home server.
  • OAuth credentials and tokens are stored encrypted, on the owner's home server or in the macOS Keychain. They are never stored in plain text and never sent anywhere except Google's and Microsoft's own sign-in servers.

Sharing

No data is sold, shared with or transferred to any third party. Data moves only between the owner's computers, Google and Microsoft.

Retention and deletion

Sync metadata is kept while the tool is in use and can be deleted at any time by removing the tool's state. Access can be revoked at any time at Google account permissions and Microsoft app permissions.

Contact

Questions about this policy: open an issue at github.com/xiaofeng-han/drive-sync-oauth.
