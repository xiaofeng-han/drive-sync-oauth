# drive-sync-oauth

Static homepage, privacy policy and terms of service for **drive-sync**, a personal tool that syncs one person's Google Drive and OneDrive. They are served by GitHub Pages and referenced from the Google OAuth consent screen's Branding page.

- Home: https://xiaofeng-han.github.io/drive-sync-oauth/
- Privacy: https://xiaofeng-han.github.io/drive-sync-oauth/privacy.html
- Terms: https://xiaofeng-han.github.io/drive-sync-oauth/terms.html

This repository contains no code.
