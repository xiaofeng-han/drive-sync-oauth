drive-sync

A personal tool that keeps one person's Google Drive and Microsoft OneDrive in sync with each other.

Personal use only. drive-sync is written and operated by Xiaofeng Han for his own accounts. It is not offered to the public, there is no sign-up, and it has no other users.

What it does

  • Copies files between the owner's Google Drive and the owner's OneDrive: two-way, or one-way in either direction.
  • Runs on the owner's own computers (a home server and a Mac). There is no drive-sync cloud service.
  • Shows sync status in a macOS menu bar app and to the owner's own automation tools.

Access it requests

  • Google Drive: https://www.googleapis.com/auth/drive, to read and write the files it keeps in sync.
  • Microsoft OneDrive: Files.ReadWrite.All, offline_access and User.Read, for the same purpose.

How this data is handled is described in the privacy policy. Use is governed by the terms of service.
